## How To Use This Pack
- Start with the reviewed primary documents above, then move into the scenario file that matches the path you want to evaluate.
- The `scenarios/` folder contains the narrative, timeline, cost, revenue, cash-flow, valuation, and risk view for each specific scenario x investment-level combination.
- Some low-capital combinations are intentionally modeled as stress cases. If a scenario shows negative cash before the investor arrives or before Pilot 2 revenue ramps, that means the path requires either front-loaded founder reserve, in-kind support, grant capital, or a bridge instrument to stay operational.
- Some smaller investor combinations are best interpreted as angel / SAFE / bridge rounds rather than a full institutional seed round.
