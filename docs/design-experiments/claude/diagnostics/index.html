Variation Summary

V1: Operational Clarity

Sharper borders, bolder type weights, 3px emerald left-bar accents, pulsing active states, uppercase section titles. Lab dispatch board feel.

V2: Calm Clinical

Softer fills (#34D399 greens, #93C5FD blues), medium weights, more whitespace, #EDF2F7 borders, paper-like surfaces. Quiet clinical document feel.

V3: Tenadoc-Inspired

Monospace order IDs, 4-color pipelines, #F1F5F9 page bg, cards with shadow, credential badges, operational banners. LIS specimen dashboard feel.
