Variation Overview

V1: Operational Clarity

Data Dense

Tighter spacing, sharper 6px-radius status chips, framed tables with alternating rows, 3px left-border accent on health cards.

  • Filled tab bar + bottom border
  • 6px radius status badges
  • Alternating row tints (#FAFBFC)
  • Table header bg: #F1F5F9
  • Disabled rows at 0.7 opacity
  • Color-coded Enable/Disable buttons

V2: Premium Guided

Polished SaaS

Fraunces serif headings, gradient fills, richer shadows, generous spacing, micro-interactions on hover.

  • Fraunces serif page title (28px)
  • Gradient tab active state
  • 16px radius health cards with shadow
  • 12px pill badges with inner glow
  • Emerald hover wash on rows
  • Scale(1.02) on primary buttons

V3: Helium Health-Inspired

Enterprise SaaS

Underline-only tabs, dot+text status, no shadows, minimal borders, text-link actions. Data-first, decoration-last.

  • Underline-only tab bar
  • Dot + text status (no pills)
  • No outer table borders
  • Flat health cards (no shadow)
  • Text-link action buttons
  • Values in #111827 (not emerald)
