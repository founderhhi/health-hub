# Health Hub — Brand Brief for Design Experiment

## Brand Personality
Trustworthy, warm, and quietly premium.

## Tone
- Calm rather than clinical-cold
- Clear and guided rather than dense or admin-heavy
- Modern and polished rather than generic or templated

## Visual Identity
- **Primary color:** Emerald #2ECC71 (light variant #ECFDF3, dark #166534)
- **Accent:** Bio-lime #AEEA00 (secondary, used sparingly)
- **Neutrals:** Text #0B0F14, Secondary #475569, Muted #64748B, Surfaces #F8FAFC / #F1F5F9
- **Semantic:** Success (green), Warning (amber #F59E0B), Danger (red #E74C3C), Info (blue #1D4ED8)

## Typography
- **Primary UI font:** Inter
- **Hero/premium moments:** Fraunces (serif)
- **Code/mono:** SF Mono / Monaco
- **Scale:** 11/12/14/16/18/20/24/32px
- **Weights:** 400 (regular), 500 (medium), 600 (semibold), 700 (bold)

## Spacing
8px base unit: 4 / 8 / 16 / 24 / 32 / 48 / 64 / 96px

## Border Radius
4 / 8 / 12 / 16 / 24 / 9999px (pill)

## Shadows
- sm: `0 1px 2px rgba(15, 23, 42, 0.04)`
- md: `0 4px 6px rgba(15, 23, 42, 0.08)`
- lg: `0 10px 30px rgba(15, 23, 42, 0.16)`
- xl: `0 20px 40px rgba(15, 23, 42, 0.24)`

## Component Heights
Button 44px, Input 44px, Header 56px (48px mobile), Bottom Nav 64px

## Design Principles
1. Status, next step, and primary action must be obvious at a glance
2. Design for emotional reassurance: reduce stress with calm copy, visible progress, stable hierarchy
3. Prioritize mobile clarity over feature density
4. Favor distinctive but credible presentation
5. Treat loading, empty, error, and coming-soon states as first-class surfaces

## Hard Avoids
- Generic AI-dashboard aesthetics
- Purple/cyan gradients, glassmorphism, card-inside-card layouts
- Over-explaining copy and repetitive headings
- Frontend that feels unfinished, placeholder-driven, or operational instead of patient-ready

## Page Archetypes
- **Patient pages:** Mobile-first, bottom nav, greeting headers, service tiles, premium moments
- **Provider pages:** Soft surface bg (#F8FAFC), white cards, operational headers, filter rows, stepper patterns
- **Specialist pages:** Referral cards with left emerald border, urgency variants (red), count badges, tabs
- **Pharmacy pages:** Scanning focus, calm functional language, claim/dispense state clarity
- **Diagnostics pages:** Filters, order cards, status progression, state patterns
- **Admin pages:** Data tables, user management, system metrics
