# Competitor-to-Page-Type Mapping

This document maps competitors from the Health Hub business plan (V1 + V2 analysis) to page families relevant to the design experiment. Each design agent should use these mappings to inform their competitor-inspired (V3) variation.

## Page Family Mapping

### Dashboard / Home
| Competitor | Market | Relevance | Key Design Insight |
|---|---|---|---|
| Practo | India | Records + appointments home | Status-first with appointment cards, clean service grid |
| Halodoc | Indonesia | Consumer health dashboard | Action-forward tiles, health tips, $2-4 GP pricing context |
| Vezeeta | MENA/Kenya | Multi-role platform home | Doctor + patient dual portal, 60k monthly bookings UI |
| Zuri Health | Kenya | Mobile-first simplicity | SMS/WhatsApp integration cues, minimal UI |
| Babylon/eMed | UK/USA | AI triage home | AI chat entry point, symptom checker prominence |

### Queue / Inbox (Provider)

## Web Search Guidance for Agents

When researching competitor UIs, search for:
- `"[competitor name] app UI"` or `"[competitor name] dashboard screenshot"`
- `"[competitor name] doctor portal"` for provider views
- `"[competitor name] app review"` for user-shared screenshots
- Check App Store / Play Store listings for official screenshots
- Check competitor websites for product screenshots and demo videos
